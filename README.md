# land_segmentation
Нейросеть создана на базе архитектуры U-Net для автоматической классификации спутниковых снимков Земли. Обучение алгоритма планируется проводить на наборе данных DeepGlobe Land Cover Classification, чтобы модель научилась различать семь основных видов ландшафта, включая городскую застройку, сельскохозяйственные угодья и водоемы.
